LLMs are incredibly good at pumping out any code the user wants, it doesn't ask questions, its main goal is to make the user happy and create whatever necessary - and will happily create 10k slocs to do so. 

When the user isn't aware of software architecture, they are unable to steer the agent into the proper patterns to set themselves up for success. They know what they want, but the user lacks the questions to drive the agent. Essentially, the user doesn't know what they don't know, and that creates rippling effects on the codebase. 

I see repos every day made with good intent, but the person creating them didn't know the full scope of the existing architecture, nor software patterns, to actually support their vision. 

The future of software engineering may just be big picture architecture, knowing what questions to ask, what exists, and how to pair everything together to create harmonious systems.
